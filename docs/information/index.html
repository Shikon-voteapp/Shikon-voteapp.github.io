紫紺祭投票アプリ ／ サポート

このページについて

紫紺祭投票アプリの「使い方」「賞の説明」「よくある質問」「トラブルシューティング」を掲載しています。

使い方（投票の流れ）

  1. 案内に記載のURLからアプリにアクセスします。
  2. 投票券に記載の番号を入力し、本人確認を行います。
  3. 各カテゴリで対象の団体を選びます（一部の賞はスキップ可能）。
  4. 内容を確認し、送信すると投票が完了します。

賞の説明

（応援指導班・吹奏楽班は受賞を辞退しているため選択不可）

  • 紫紺賞：この文化祭を通じて、最も印象に残った団体を1つ選択します。学内の展示・催し・学年展示・露店・ステージ等が対象です。
  • 教室展示賞：教室展示の中で「最後にもう一回行くならこれだ！」と思えるクオリティが最も高かった団体を1つ選択します。
  • 学年展示賞：学年展示の中で「最後にもう一回行くならこれだ！」と思えるクオリティが最も高かった団体を1つ選択します。
  • 教室催し物賞：教室催し物の中で「最後にもう一回行くならこれだ！」と思えるクオリティが最も高かった団体を1つ選択します。
  • 部活ステージ賞：「もう一度行きたい、見たい！」と思える最も盛り上がった部活ステージ団体を1つ選択します。
  • バンド賞：「もう一度行きたい、見たい！」と思える最も盛り上がったバンド団体を1つ選択します。
  • パフォーマンス賞：「もう一度行きたい、見たい！」と思える最も盛り上がったパフォーマンス団体を1つ選択します。

サポートページについて

このページは、紫紺祭投票アプリの利用に関するガイド、よくある質問、 トラブルシューティングをまとめたサポートページです。

よくある質問

アプリが表示されない／真っ白な画面になる
  1. 通信環境を確認してください（Wi‑Fiやモバイルデータ）。
  2. ブラウザを最新に更新し、ページを再読み込みしてください。
  3. 別のブラウザ（Chrome, Edge, Safari 等）でもお試しください。
  4. Mac OS、iPad OSでの動作確認は行っていないため、動作対象外となります。
投票完了にならない／エラーメッセージが出る
  1. 電波状況を確認し、時間をおいて再度お試しください。
  2. アプリを閉じてから再度開き、投票をやり直してください。
  3. エラーメッセージの内容を控えてお知らせください。

トラブルシューティング

  • ✓ ブラウザのシークレットモードで再度アクセス
  • ✓ ブラウザのキャッシュ削除後に再読み込み

  • ✓ ネットワークのフィルタ設定を確認
